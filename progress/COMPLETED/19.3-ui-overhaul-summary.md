## Technical Details

### Theme Access Pattern
```qml
import Core 1.0 as Core

Rectangle {
    color: Core.Theme.background

    Text {
        color: Core.Theme.textPrimary
        font.pixelSize: Core.Theme.fontSizeMd
    }
}
```

### Component Usage Pattern
```qml
import Core 1.0 as Core

Core.Button {
    text: "Action"
    variant: "tactical"
    onClicked: doSomething()
}
```
