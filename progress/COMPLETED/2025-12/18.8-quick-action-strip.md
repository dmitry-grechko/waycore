## Description

Implement a bottom quick action strip that provides instant access to critical functions without leaving the current app. This is essential for field use where users need quick access to flashlight, communications, screen lock, and power controls.

## Context

In outdoor/emergency situations, users need to:
- Turn on flashlight without navigating away
- Quickly access communications
- Lock the screen to prevent accidental touches
- Access power/shutdown options

The quick action strip sits at the bottom of the screen and is always accessible.

## Design Specifications

### Dimensions
- **Height**: 80-96px (large touch targets)
- **Padding**: 16px horizontal, 12px vertical
- **Background**: Surface color or transparent gradient

### Quick Actions (Default Set)

| Action | Icon | Label | Behavior |
|--------|------|-------|----------|
| Flashlight | 🔦 | FLASH | Toggle flashlight (instant) |
| Comms | 📶 | COMMS | Open Meshtastic quick view |
| Lock | 🔒 | LOCK | Lock screen immediately |
| Power | ⚡ | POWER | Open power menu |

### Button Specifications
- **Size**: ~70×70px touch target
- **Icon size**: 24-32px
- **Label**: ALL CAPS, 10-11px, letter-spacing 1px
- **Active state**: Filled background, icon color change
- **Pressed state**: Scale 0.95, slight color change

## Implementation

### QuickActionStrip.qml

```qml
import QtQuick 2.15
import "components" as UI

Rectangle {
    id: quickStrip
    height: 96
    color: Theme.surface

    // Optional: gradient overlay at top for visual separation
    Rectangle {
        anchors.top: parent.top
        width: parent.width
        height: 1
        color: Theme.divider
    }

    Row {
        anchors.centerIn: parent
        spacing: 24

        UI.QuickAction {
            icon: flashlightOn ? "🔦" : "🔦"
            label: "FLASH"
            active: flashlightOn
            onClicked: toggleFlashlight()
        }

        UI.QuickAction {
            icon: "📶"
            label: "COMMS"
            badge: unreadMessages > 0 ? unreadMessages : 0
            onClicked: openQuickComms()
        }

        UI.QuickAction {
            icon: "🔒"
            label: "LOCK"
            onClicked: lockScreen()
        }

        UI.QuickAction {
            icon: "⚡"
            label: "POWER"
            onClicked: powerMenu.open()
        }
    }

    // State
    property bool flashlightOn: false
    property int unreadMessages: MeshBridge ? MeshBridge.unreadCount : 0

    // Actions
    function toggleFlashlight() {
        flashlightOn = !flashlightOn
        if (SensorBridge) {
            SensorBridge.setFlashlight(flashlightOn)
        }
    }

    function openQuickComms() {
        // Show quick comms overlay
        quickCommsPopup.open()
    }

    function lockScreen() {
        // Implement screen lock
        lockOverlay.visible = true
    }

    // Power menu
    PowerMenu {
        id: powerMenu
    }

    // Quick comms popup
    Popup {
        id: quickCommsPopup
        anchors.centerIn: Overlay.overlay
        width: parent.width - 32
        height: 300
        modal: true

        // Show recent messages and quick reply
        Column {
            anchors.fill: parent
            anchors.margins: 16

            Text {
                text: "RECENT MESSAGES"
                color: Theme.textSecondary
                font.pixelSize: 12
                font.letterSpacing: 1
            }

            // Message list
            ListView {
                width: parent.width
                height: 200
                model: MeshBridge ? MeshBridge.recentMessages : []
                delegate: Text {
                    text: modelData.from + ": " + modelData.text
                    color: Theme.textPrimary
                }
            }

            // Quick reply
            UI.Button {
                text: "Open Meshtastic"
                width: parent.width
                onClicked: {
                    quickCommsPopup.close()
                    shell.navigateTo("Meshtastic")
                }
            }
        }
    }
}
```

### QuickAction.qml

```qml
import QtQuick 2.15

Rectangle {
    id: action
    width: 70
    height: 70
    radius: 12
    color: active ? Theme.primaryAccent : "transparent"
    border.color: Theme.divider
    border.width: active ? 0 : 1

    property string icon: ""
    property string label: ""
    property bool active: false
    property int badge: 0

    signal clicked()

    Column {
        anchors.centerIn: parent
        spacing: 4

        Text {
            anchors.horizontalCenter: parent.horizontalCenter
            text: icon
            font.pixelSize: 24
        }

        Text {
            anchors.horizontalCenter: parent.horizontalCenter
            text: label
            color: active ? Theme.textPrimary : Theme.textSecondary
            font.pixelSize: 11
            font.weight: Font.Medium
            font.letterSpacing: 1
        }
    }

    // Badge for notifications
    Rectangle {
        visible: badge > 0
        anchors.top: parent.top
        anchors.right: parent.right
        anchors.margins: -4
        width: 20
        height: 20
        radius: 10
        color: Theme.error

        Text {
            anchors.centerIn: parent
            text: badge > 9 ? "9+" : badge
            color: "white"
            font.pixelSize: 10
            font.bold: true
        }
    }

    MouseArea {
        anchors.fill: parent
        onClicked: action.clicked()
        onPressed: action.scale = 0.95
        onReleased: action.scale = 1.0
    }

    Behavior on scale {
        NumberAnimation { duration: 100 }
    }

    Behavior on color {
        ColorAnimation { duration: 150 }
    }
}
```

### PowerMenu.qml

```qml
import QtQuick 2.15
import QtQuick.Controls 2.15

Popup {
    id: powerMenu
    anchors.centerIn: Overlay.overlay
    width: 280
    height: 300
    modal: true
    closePolicy: Popup.CloseOnEscape | Popup.CloseOnPressOutside

    background: Rectangle {
        color: Theme.surface
        radius: 16
        border.color: Theme.divider
    }

    Column {
        anchors.fill: parent
        anchors.margins: 16
        spacing: 8

        Text {
            text: "POWER OPTIONS"
            color: Theme.textSecondary
            font.pixelSize: 12
            font.letterSpacing: 1
        }

        Item { height: 8 }  // Spacer

        // Power options
        PowerMenuItem {
            icon: "🔋"
            label: "Battery Saver"
            sublabel: "Reduce background activity"
            toggle: true
            checked: batterySaverEnabled
            onClicked: batterySaverEnabled = !batterySaverEnabled
        }

        PowerMenuItem {
            icon: "🌙"
            label: "Sleep Mode"
            sublabel: "Turn off display, keep radios"
            onClicked: {
                powerMenu.close()
                enterSleepMode()
            }
        }

        PowerMenuItem {
            icon: "🔄"
            label: "Restart"
            sublabel: "Restart device"
            onClicked: confirmRestart()
        }

        PowerMenuItem {
            icon: "⏹️"
            label: "Shutdown"
            sublabel: "Power off completely"
            dangerous: true
            onClicked: confirmShutdown()
        }
    }

    property bool batterySaverEnabled: false
}

// PowerMenuItem helper component
component PowerMenuItem: Rectangle {
    width: parent.width
    height: 56
    color: mouseArea.containsMouse ? Theme.surfaceElevated : "transparent"
    radius: 8

    property string icon: ""
    property string label: ""
    property string sublabel: ""
    property bool toggle: false
    property bool checked: false
    property bool dangerous: false

    signal clicked()

    Row {
        anchors.fill: parent
        anchors.margins: 12
        spacing: 12

        Text {
            text: icon
            font.pixelSize: 24
            anchors.verticalCenter: parent.verticalCenter
        }

        Column {
            anchors.verticalCenter: parent.verticalCenter

            Text {
                text: label
                color: dangerous ? Theme.error : Theme.textPrimary
                font.pixelSize: 16
            }
            Text {
                text: sublabel
                color: Theme.textSecondary
                font.pixelSize: 12
            }
        }

        Item { Layout.fillWidth: true }

        // Toggle switch if applicable
        Switch {
            visible: toggle
            checked: parent.parent.checked
            anchors.verticalCenter: parent.verticalCenter
        }
    }

    MouseArea {
        id: mouseArea
        anchors.fill: parent
        hoverEnabled: true
        onClicked: parent.clicked()
    }
}
```

## Visibility Options

The quick action strip can be shown:

1. **Always visible** (persistent at bottom)
2. **Swipe up to reveal** (hidden by default)
3. **On home screen only**
4. **Configurable in settings**

Recommend starting with **always visible** for MVP.
