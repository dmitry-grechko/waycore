# Task: Home Grid Enhancement

**Phase**: Phase 18 - Modular App Ecosystem
**Task ID**: 18.9
**Status**: COMPLETED
**Started**: 2025-12-29
**Completed**: 2025-12-29
**Priority**: Medium

## Description

Enhance the home grid to dynamically display apps from the app registry with a tiered layout. Tier 1 apps appear on the home screen (2×3 grid), while Tier 2 apps are accessed through a System Hub.

## Target Design

```
┌──────────────────────────────────────────┐

├──────────────┴───────────────────────────┤

└──────────────────────────────────────────┘
```

## Tier Definitions

**Tier 1** (Home - 6 slots max):
- SOS (position 0, always visible)
- Messages/Meshtastic (position 1)
- Map (position 2)
- Identify/Camera (position 3)
- AI (position 4)
- System Hub (position 5, always last)

**Tier 2** (System Hub):
- Notes, Compass, Camera, Gallery
- Sensors, Modules, Settings
- Any additional apps

## Implementation

### Home.qml

```qml
import QtQuick 2.15
import "components" as UI

Rectangle {
    id: home
    color: Theme.background

    // Title
    Text {
        id: title
        text: "WAYCORE"
        color: Theme.textPrimary
        font.pixelSize: Theme.h2Size
        font.weight: Font.Bold
        font.letterSpacing: 2
        anchors.top: parent.top
        anchors.horizontalCenter: parent.horizontalCenter
        anchors.topMargin: Theme.spacingLarge
    }

    // 2×3 Grid for Tier 1 apps
    GridView {
        id: appGrid
        anchors.top: title.bottom
        anchors.bottom: parent.bottom
        anchors.left: parent.left
        anchors.right: parent.right
        anchors.margins: Theme.spacingMedium

        cellWidth: width / 2
        cellHeight: (height - Theme.spacingMedium) / 3

        model: AppBridge ? AppBridge.tier1Apps : fallbackModel

        delegate: UI.AppTile {
            width: appGrid.cellWidth - Theme.spacingSmall
            height: appGrid.cellHeight - Theme.spacingSmall
            appId: modelData.id
            appName: modelData.name
            appIcon: modelData.icon
            isEmergency: modelData.category === "emergency"

            onClicked: {
                if (modelData.id === "com.waycore.system") {
                    shell.navigateTo("SystemHub")
                } else {
                    shell.navigateToApp(modelData.id)
                }
            }
        }
    }

    // Fallback model for testing without AppBridge
    ListModel {
        id: fallbackModel
        ListElement { id: "com.waycore.sos"; name: "SOS"; icon: "🚨"; category: "emergency" }
        ListElement { id: "com.waycore.meshtastic"; name: "Messages"; icon: "💬"; category: "communication" }
        ListElement { id: "com.waycore.maps"; name: "Map"; icon: "🗺️"; category: "navigation" }
        ListElement { id: "com.waycore.camera"; name: "Identify"; icon: "📷"; category: "media" }
        ListElement { id: "com.waycore.ai"; name: "AI"; icon: "🤖"; category: "ai" }
        ListElement { id: "com.waycore.system"; name: "System"; icon: "⚙️"; category: "system" }
    }
}
```

### SystemHub.qml

```qml
import QtQuick 2.15
import "components" as UI

Rectangle {
    id: systemHub
    color: Theme.background

    signal closeRequested()

    // App bar
    UI.AppBar {
        id: appBar
        title: "System"
        showBackButton: true
        onBackClicked: closeRequested()
    }

    // 3-column grid for Tier 2 apps
    GridView {
        id: appGrid
        anchors.top: appBar.bottom
        anchors.bottom: parent.bottom
        anchors.left: parent.left
        anchors.right: parent.right
        anchors.margins: Theme.spacingMedium

        cellWidth: width / 3
        cellHeight: 120

        model: AppBridge ? AppBridge.tier2Apps : fallbackModel

        delegate: UI.AppTile {
            width: appGrid.cellWidth - Theme.spacingSmall
            height: appGrid.cellHeight - Theme.spacingSmall
            appId: modelData.id
            appName: modelData.name
            appIcon: modelData.icon
            compact: true

            onClicked: shell.navigateToApp(modelData.id)
        }
    }

    ListModel {
        id: fallbackModel
        ListElement { id: "com.waycore.notes"; name: "Notes"; icon: "📝" }
        ListElement { id: "com.waycore.compass"; name: "Compass"; icon: "🧭" }
        ListElement { id: "com.waycore.camera"; name: "Camera"; icon: "📷" }
        ListElement { id: "com.waycore.gallery"; name: "Gallery"; icon: "🖼️" }
        ListElement { id: "com.waycore.sensors"; name: "Sensors"; icon: "📊" }
        ListElement { id: "com.waycore.modules"; name: "Modules"; icon: "🔌" }
        ListElement { id: "com.waycore.settings"; name: "Settings"; icon: "⚙️" }
    }
}
```
