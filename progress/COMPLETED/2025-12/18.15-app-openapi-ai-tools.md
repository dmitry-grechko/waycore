# Task: App OpenAPI Specs for AI Tools

**Phase**: Phase 18 - Third-Party App Ecosystem
**Task ID**: 18.15
**Status**: COMPLETED
**Started**: 2025-12-29
**Completed**: 2025-12-29
**Priority**: Medium

## Description

Enable third-party apps to expose their APIs as OpenAPI specifications, which are then automatically discovered and made available to the AI agent as tools. This allows app developers to extend AI capabilities without modifying core AI code.

## Current State (Problems)

1. **No app API exposure**: Third-party apps cannot add AI tools
2. **Manual integration**: Each app-AI integration requires core changes
3. **Limited extensibility**: AI capabilities fixed at build time
4. **No standard**: Apps have no way to advertise capabilities to AI

## Target State (Goals)

1. **Standard interface**: Apps expose OpenAPI specs in standard location
2. **Auto-discovery**: AI automatically discovers app APIs on startup
3. **Dynamic tools**: New apps add new AI capabilities
4. **Developer-friendly**: Simple process to add AI tools

## App Developer Requirements

### 1. OpenAPI Spec Endpoint

Apps must expose their OpenAPI spec at a standard endpoint:

```
GET /api/openapi.json
```

### 2. AI Tool Metadata

OpenAPI operations intended for AI use should include `x-ai-tool` extension:

```yaml
paths:
  /api/weather/forecast:
    get:
      operationId: get_weather_forecast
      summary: Get weather forecast for location
      x-ai-tool:
        enabled: true
        description: "Get weather forecast for the next 24-48 hours"
        examples:
          - "What's the weather going to be like tomorrow?"
          - "Will it rain this afternoon?"
        category: "weather"
```

### 3. Manifest Declaration

Apps declare AI capabilities in their manifest:

```yaml
# app.manifest.yaml
id: weather-app
name: Weather
version: 1.0.0

ai:
  enabled: true
  tools:
    - get_weather_forecast
    - get_current_conditions
  description: "Weather forecasting and current conditions"
```

### AI Tool Discovery

```python
from __future__ import annotations

import httpx
from typing import Any

from device.services.module_manager.registry import AppRegistry


class AIToolDiscovery:
    """Discover AI tools from installed apps."""

    def __init__(self, app_registry: AppRegistry) -> None:
        self.apps = app_registry

    async def discover_all(self) -> list[dict[str, Any]]:
        """Discover all AI tools from all apps."""
        tools = []

        for app in self.apps.list_apps():
            if not app.manifest.ai or not app.manifest.ai.enabled:
                continue

            app_tools = await self._discover_app_tools(app)
            tools.extend(app_tools)

        return tools

    async def _discover_app_tools(self, app) -> list[dict[str, Any]]:
        """Discover tools from a single app."""
        spec_url = f"http://{app.id}:{app.port}/api/openapi.json"

        try:
            async with httpx.AsyncClient(timeout=5.0) as client:
                resp = await client.get(spec_url)
                if resp.status_code != 200:
                    return []

                spec = resp.json()
                return self._parse_tools(spec, app)

        except Exception:
            return []

    def _parse_tools(self, spec: dict, app) -> list[dict[str, Any]]:
        """Parse OpenAPI spec for AI tools."""
        tools = []

        for path, methods in spec.get("paths", {}).items():
            for method, operation in methods.items():
                if method not in ["get", "post", "put", "delete"]:
                    continue

                ai_tool = operation.get("x-ai-tool", {})
                if not ai_tool.get("enabled", False):
                    continue

                tools.append({
                    "name": f"{app.id}_{operation['operationId']}",
                    "description": ai_tool.get("description", operation.get("summary", "")),
                    "category": ai_tool.get("category", "app"),
                    "app_id": app.id,
                    "endpoint": f"http://{app.id}:{app.port}{path}",
                    "method": method.upper(),
                    "parameters": operation.get("parameters", []),
                    "request_body": operation.get("requestBody"),
                })

        return tools
```

### App Tools MCP Server

```python
from __future__ import annotations

from mcp.server import Server
from mcp.types import Tool, TextContent

from .registry import AppToolRegistry

app = Server("waycore-app-tools")
registry = AppToolRegistry()


@app.list_tools()
async def list_tools() -> list[Tool]:
    """List all app-provided tools."""
    return registry.get_all_tools()


@app.call_tool()
async def call_tool(name: str, arguments: dict) -> list[TextContent]:
    """Execute an app tool."""
    result = await registry.execute_tool(name, arguments)

    if "error" in result:
        return [TextContent(type="text", text=f"Error: {result['error']}")]

    import json
    return [TextContent(type="text", text=json.dumps(result, indent=2))]
```

## Example: Weather App Integration

### App OpenAPI Spec

```yaml
openapi: 3.0.0
info:
  title: Weather App API
  version: 1.0.0

paths:
  /api/forecast:
    get:
      operationId: get_forecast
      summary: Get weather forecast
      x-ai-tool:
        enabled: true
        description: "Get weather forecast for current location or specified coordinates"
        examples:
          - "What's the weather forecast?"
          - "Will it rain tomorrow?"
      parameters:
        - name: days
          in: query
          schema:
            type: integer
            default: 3
          description: Number of days to forecast
      responses:
        200:
          description: Weather forecast
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/Forecast'
```

### AI Interaction

```
User: "What's the weather going to be like tomorrow?"

AI Agent:
1. Recognizes weather query
2. Finds weather_app_get_forecast tool
3. Calls tool with days=2
4. Gets response: {"tomorrow": {"high": 72, "low": 58, "conditions": "Partly cloudy"}}
5. Responds: "Tomorrow will be partly cloudy with a high of 72°F and low of 58°F."
```
