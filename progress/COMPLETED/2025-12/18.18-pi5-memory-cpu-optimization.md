# 18.18 Pi 5 Memory and CPU Optimization

**Status**: COMPLETED
**Priority**: Medium
**Phase**: 18 - Platform Polish
**Dependencies**: None

## Overview

Optimize Waycore's memory and CPU usage for Raspberry Pi 5 deployment. Current configuration targets 4GB RAM, but Pi 5 supports up to 8GB. Additionally, several optimizations can reduce memory footprint, improve startup time, and extend battery life.

## Current State

| Component | RAM Usage | Notes |
|-----------|-----------|-------|
| Phi-3 Mini (Q4_K_M) | ~2.5-3.0 GB | Loaded entirely into RAM |
| Embedding Model (MiniLM) | ~150-200 MB | For RAG semantic search |
| MobileNetV3 | ~50 MB | Vision model |
| 5 MCP Subprocess servers | ~300-500 MB | Each Python process has overhead |
| Docker + OS overhead | ~500-800 MB | Kernel, containers |
| **Total** | **~3.5-4.5 GB** | When AI is actively loaded |

## Implementation Details

### 1. Enable Memory-Mapped Loading (High Priority)

**File**: `device/services/ai_service/models/phi3_runner.py`

```python
self._llm = Llama(
    model_path=str(self._model_path),
    n_ctx=self._n_ctx,
    n_threads=self._n_threads,
    n_gpu_layers=0,
    verbose=False,
    use_mmap=True,   # Memory-map the model file
    use_mlock=False, # Allow swapping if needed
)
```

**Benefits**: ~30% faster startup, lower initial memory footprint.

- Max: 4096 for complex conversations

### 5. Idle Model Unloading (Medium Priority)

**File**: `device/services/ai_service/service.py`

```python
IDLE_UNLOAD_SECONDS = int(os.getenv("AI_IDLE_UNLOAD_SECONDS", "300"))

async def _check_idle_unload(self):
    """Unload models after idle timeout to save memory."""
    if time.time() - self._last_inference_time > IDLE_UNLOAD_SECONDS:
        registry.unload_all()
        logger.info("Unloaded models due to idle timeout")
```
