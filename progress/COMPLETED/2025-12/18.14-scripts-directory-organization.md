## Description

Reorganize the `scripts/` directory for better maintainability and discoverability. Currently, all scripts are in a flat structure with inconsistent naming conventions and no documentation.

## Current State (Problems)

1. **Flat structure**: All 13 scripts in root directory with no organization
2. **Inconsistent naming**: Mix of hyphens (`task-start.sh`) and underscores (`task_start.py`)
3. **Wrapper redundancy**: Shell scripts that only call Python scripts (e.g., `task-start.sh` → `task_start.py`)
4. **No documentation**: No README explaining script purposes and usage
5. **Mixed concerns**: Development, task management, code generation, and model scripts all together

### Shell Wrapper Elimination

Current wrapper pattern:
```bash
# task-start.sh
#!/bin/bash
python3 "$(dirname "$0")/task_start.py" "$@"
```

Can be replaced by calling Python directly:
```bash
# Usage becomes:
python scripts/task_start.py 18.1
# Or with executable permission:
./scripts/task_start.py 18.1
```
