# Task: Status Bar Redesign

**Phase**: Phase 18 - Modular App Ecosystem
**Task ID**: 18.7
**Status**: COMPLETED

**Completed**: 2025-12-29
**Priority**: Medium

## Description

Redesign the status bar to be more information-dense, power-efficient, and field-ready. The new status bar will display critical information at a glance without requiring interaction.

## Context

The current status bar is basic (time and battery). For field use, users need quick access to:
- Battery level with percentage
- Time (24h format)
- Temperature (from sensors)
- Connectivity status (LTE, WiFi, GPS, Mesh)

The design must be:
- Always visible (fixed at top)
- High contrast for outdoor visibility
- Power-efficient (minimal animations, dark background)
- Touch-friendly (long-press for details)

## Current State

**Location**: `device/apps/ui/qml/StatusBar.qml`
**Height**: 56px (Theme.appBarHeight)
**Features**: Time, battery icon

## Design Specifications

### Dimensions
- **Height**: 64px (increased for touch)
- **Padding**: 16px horizontal
- **Background**: Pure black (#000000) for OLED

### Layout (Left to Right)

**Left Section** (Device Status):
- Battery icon + percentage (e.g., "🔋 78%")
- Time in 24h format (e.g., "14:32")
- Temperature with icon (e.g., "🌡️ 18°C")

**Right Section** (Connectivity):
- LTE indicator (📶)
- WiFi indicator (🛜 or 📡)
- GPS indicator (🛰)
- Mesh indicator (📡)

### Typography
- Font size: 16px (bodySize)
- Font weight: Medium/Bold
- Color: White (#FFFFFF)

### Indicator States
- **Active**: Full opacity (1.0)
- **Inactive**: Dimmed (0.3 opacity)
- **Warning**: Amber color
- **Error/Critical**: Red color

## Implementation

### StatusBar.qml

```qml
import QtQuick 2.15
import "components" as UI

Rectangle {
    id: statusBar
    height: 64
    color: "#000000"  // Pure black for OLED

    // Left section: Device info
    Row {
        id: leftSection
        anchors.left: parent.left
        anchors.leftMargin: 16
        anchors.verticalCenter: parent.verticalCenter
        spacing: 16

        // Battery
        Row {
            spacing: 4
            Text {
                text: getBatteryIcon(batteryLevel)
                font.pixelSize: 18
            }
            Text {
                text: batteryLevel + "%"
                color: batteryLevel < 20 ? Theme.error : Theme.textPrimary
                font.pixelSize: 16
                font.weight: Font.Medium
            }
        }

        // Time
        Text {
            text: Qt.formatTime(new Date(), "HH:mm")
            color: Theme.textPrimary
            font.pixelSize: 18
            font.weight: Font.Bold
        }

        // Temperature
        Row {
            spacing: 4
            visible: temperature !== null
            Text {
                text: "🌡️"
                font.pixelSize: 16
            }
            Text {
                text: temperature + "°C"
                color: Theme.textPrimary
                font.pixelSize: 16
            }
        }
    }

    // Right section: Connectivity
    Row {
        id: rightSection
        anchors.right: parent.right
        anchors.rightMargin: 16
        anchors.verticalCenter: parent.verticalCenter
        spacing: 12

        UI.StatusIndicator {
            icon: "📶"
            active: hasLTE
            tooltip: "Cellular"
        }

        UI.StatusIndicator {
            icon: "🛜"
            active: hasWiFi
            tooltip: "WiFi"
        }

        UI.StatusIndicator {
            icon: "🛰"
            active: hasGPS
            tooltip: "GPS"
        }

        UI.StatusIndicator {
            icon: "📡"
            active: hasMesh
            tooltip: "Mesh"
        }
    }

    // Properties (from SensorBridge or mocked)
    property int batteryLevel: SensorBridge ? SensorBridge.batteryLevel : 85
    property var temperature: SensorBridge ? SensorBridge.temperature : 18
    property bool hasLTE: false  // Future
    property bool hasWiFi: true
    property bool hasGPS: SensorBridge ? SensorBridge.hasGpsFix : false
    property bool hasMesh: MeshBridge ? MeshBridge.isConnected : false

    // Long-press handler for detailed status
    MouseArea {
        anchors.fill: parent
        onPressAndHold: {
            statusPopup.open()
        }
    }

    // Timer for clock updates
    Timer {
        interval: 1000
        running: true
        repeat: true
        onTriggered: {
            // Force binding update
            var now = new Date()
            timeText.text = Qt.formatTime(now, "HH:mm")
        }
    }

    function getBatteryIcon(level) {
        if (level > 80) return "🔋"
        if (level > 50) return "🔋"
        if (level > 20) return "🪫"
        return "🪫"  // Low battery
    }
}
```

### Detailed Status Popup

```qml
Popup {
    id: statusPopup
    anchors.centerIn: Overlay.overlay
    width: parent.width - 32
    height: 300
    modal: true

    background: Rectangle {
        color: Theme.surface
        radius: 12
    }

    Column {
        anchors.fill: parent
        anchors.margins: 16
        spacing: 12

        // Battery details
        Row {
            width: parent.width
            Text { text: "Battery"; color: Theme.textSecondary }
            Text {
                text: batteryLevel + "% (" + (isCharging ? "Charging" : "Discharging") + ")"
                color: Theme.textPrimary
                anchors.right: parent.right
            }
        }

        // Temperature details
        Row {
            width: parent.width
            Text { text: "Temperature"; color: Theme.textSecondary }
            Text {
                text: temperature + "°C"
                color: Theme.textPrimary
                anchors.right: parent.right
            }
        }

        // GPS details
        Row {
            width: parent.width
            Text { text: "GPS"; color: Theme.textSecondary }
            Text {
                text: hasGPS ? "Fix (" + gpsSatellites + " sats)" : "No fix"
                color: hasGPS ? Theme.success : Theme.textSecondary
                anchors.right: parent.right
            }
        }

        // ... more details
    }
}
```
