## Description

Define the app manifest schema and corresponding Python/QML types that will be used throughout the modular app ecosystem. The manifest serves as the contract between an app and the core system, declaring capabilities, dependencies, and entry points.

## Context

This is the foundation task for the modular app architecture. All subsequent tasks depend on this schema being well-defined. The manifest must support:
- App identification and metadata
- Frontend entry point (QML)
- Backend service registration (optional)
- Required sensors and permissions
- Feature flags and configuration

## Manifest Schema

```json
{
  "id": "com.waycore.compass",
  "name": "Compass",
  "version": "1.0.0",
  "description": "Navigation compass with heading and bearing",
  "icon": "🧭",
  "category": "navigation",
  "entry": {
    "qml": "qml/CompassMain.qml",
    "backend": "backend/service.py"
  },
  "permissions": [
    "sensors.magnetometer",
    "sensors.gps"
  ],
  "sensors": [
    {"type": "magnetometer", "required": true},
    {"type": "gps", "required": false}
  ],
  "tier": 2,
  "homePosition": null,
  "enabled": true,
  "minCoreVersion": "1.0.0"
}
```

### Field Definitions

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | Yes | Unique identifier (reverse domain format) |
| `name` | string | Yes | Display name (max 12 chars for UI) |
| `version` | string | Yes | Semantic version (X.Y.Z) |
| `description` | string | No | Short description |
| `icon` | string | Yes | Emoji or icon name |
| `category` | enum | No | App category for grouping |
| `entry.qml` | string | Yes | Path to main QML file (relative to app dir) |
| `entry.backend` | string | No | Path to backend module (optional) |
| `permissions` | array | No | Required system permissions |
| `sensors` | array | No | Required/optional sensors |
| `tier` | int | No | UI tier (1=home, 2=system hub) |
| `homePosition` | int | No | Fixed position on home grid (null=auto) |
| `enabled` | bool | No | Whether app is enabled (default: true) |
| `minCoreVersion` | string | No | Minimum core version required |

### Categories (Fixed List)

App developers must choose from this predefined list of categories:

| Category | Description | Example Apps |
|----------|-------------|--------------|
| `emergency` | SOS, emergency features | SOS Beacon, Emergency Alerts |
| `communication` | Messaging, radio, mesh networking | Meshtastic, Radio, Contacts |
| `navigation` | Maps, compass, GPS, waypoints | Compass, Maps, GPS Tracker |
| `media` | Camera, gallery, audio/video | Camera, Gallery, Voice Recorder |
| `ai` | AI-powered features | AI Assistant, Image Recognition |
| `utilities` | General-purpose tools | Calculator, Flashlight, Notes, Unit Converter |
| `sport` | Fitness, training, outdoor sports | Shot Timer, Step Counter, Workout Timer |
| `health` | Health monitoring, biometrics | Heart Rate, Blood Oxygen, First Aid Guide |
| `weather` | Weather and environmental data | Weather, Barometer, UV Index |
| `sensors` | Raw sensor access, diagnostics | Sensor Viewer, Altimeter, Rangefinder |
| `system` | Device settings, configuration | Settings, Modules, About |

### Tiers

- **Tier 1**: Always on home screen (max 6 apps)
- **Tier 2**: In system hub / sub-menu (all other apps)

## Implementation

### Python Schema (Pydantic)

```python
from __future__ import annotations

from enum import Enum
from typing import Optional

from pydantic import BaseModel, Field


class AppCategory(str, Enum):
    EMERGENCY = "emergency"
    COMMUNICATION = "communication"
    NAVIGATION = "navigation"
    MEDIA = "media"
    AI = "ai"
    UTILITIES = "utilities"
    SPORT = "sport"
    HEALTH = "health"
    WEATHER = "weather"
    SENSORS = "sensors"
    SYSTEM = "system"


class SensorRequirement(BaseModel):
    type: str
    required: bool = True


class AppEntry(BaseModel):
    qml: str = Field(..., description="Relative path to main QML file")
    backend: Optional[str] = Field(None, description="Relative path to backend module")


class AppManifest(BaseModel):
    id: str = Field(..., pattern=r"^[a-z][a-z0-9]*(\.[a-z][a-z0-9]*)+$")
    name: str = Field(..., max_length=12)
    version: str = Field(..., pattern=r"^\d+\.\d+\.\d+$")
    description: Optional[str] = None
    icon: str
    category: Optional[AppCategory] = None
    entry: AppEntry
    permissions: list[str] = Field(default_factory=list)
    sensors: list[SensorRequirement] = Field(default_factory=list)
    tier: int = Field(default=2, ge=1, le=2)
    home_position: Optional[int] = Field(None, alias="homePosition")
    enabled: bool = True
    min_core_version: Optional[str] = Field(None, alias="minCoreVersion")
```
