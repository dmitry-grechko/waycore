# Task: Power-Efficient Theme & Daylight Mode

**Phase**: Phase 18 - Modular App Ecosystem

**Completed**: 2025-12-29

## Description

Finalize the power-efficient theme optimized for OLED displays and implement a toggleable daylight mode for outdoor visibility. The theme should minimize pixel rendering (dark backgrounds) while maintaining high contrast for field use.

## Context

OLED displays consume less power when displaying darker colors, especially pure black (#000000) which turns pixels completely off. For a field device with limited battery, optimizing the UI for power efficiency is critical.

Additionally, bright sunlight can make dark UIs hard to read, so a daylight mode (light theme) should be available.

## Theme Specifications

### Default (Dark/Power-Save Mode)

```qml
// OLED-Optimized Dark Theme
readonly property color background: "#000000"      // Pure black (OLED off)
readonly property color backgroundAlt: "#0A0D0B"   // Near-black with green tint
readonly property color surface: "#141917"          // Very dark surface
readonly property color surfaceElevated: "#1E2520" // Slightly lighter
readonly property color surfaceHighlight: "#2B3D33"// Accent surface

// High contrast text

readonly property color textSecondary: "#A8B5AB"
```

### Settings Integration

Add theme toggle to Settings:

```qml
// In Settings app
ListItem {
    icon: Theme.daylightMode ? "☀️" : "🌙"
    text: "Display Mode"
    secondaryText: Theme.daylightMode ? "Daylight" : "Power Save"
    trailing: Switch {
        checked: Theme.daylightMode
        onCheckedChanged: Theme.daylightMode = checked
    }
}
```
