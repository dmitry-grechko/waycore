## Description

Create an SOS emergency app that allows users to trigger an SOS signal with confirmation to prevent accidental activation. When triggered, the app activates an audible SOS signal using Morse code (... --- ...) and optionally broadcasts an emergency message over the mesh network. The signal should continue until manually stopped.

### Features

1. **Confirmation Dialog**
   - Require confirmation before triggering SOS (prevent accidental triggers)
   - Clear warning that SOS will be activated
   - Two-step confirmation: tap SOS button → confirm activation

2. **Audible SOS Signal**
   - Play Morse code SOS pattern: ... --- ... (dit dit dit dah dah dah dit dit dit)
   - Continuous loop until manually stopped
   - Volume control or max volume option
   - Mute/unmute toggle without stopping SOS broadcast

3. **Visual SOS Indicator**
   - Screen flashes or displays SOS pattern
   - Large, obvious indicator that SOS is active
   - Red color scheme for emergency visibility

4. **SOS Cancellation**
   - Large, obvious "Stop SOS" button
   - Confirmation before stopping (optional, to prevent accidental stop)
   - Clear feedback when SOS is deactivated

5. **Mesh Network Broadcast** (if comms available)
   - Send SOS message over mesh network
   - Include GPS coordinates if available
   - Repeat broadcast periodically while active
   - Show broadcast status (sent/failed)

### Morse Code Timing

Standard Morse code timing for SOS:
- Dit (short): 1 unit
- Dah (long): 3 units
- Gap between elements: 1 unit
- Gap between letters: 3 units
- One unit = ~100-200ms for audible clarity

```
SOS Pattern: · · · — — — · · ·
Timing:      1 1 1 3 3 3 1 1 1 (with gaps)
```

## Implementation Notes

### Morse Code Audio Generation

```python
# SOS Morse code timing
UNIT_MS = 150  # Base time unit in milliseconds
DIT = UNIT_MS
DAH = UNIT_MS * 3
ELEMENT_GAP = UNIT_MS
LETTER_GAP = UNIT_MS * 3
WORD_GAP = UNIT_MS * 7

SOS_PATTERN = [
    # S: ...
    ("beep", DIT), ("silence", ELEMENT_GAP),
    ("beep", DIT), ("silence", ELEMENT_GAP),
    ("beep", DIT), ("silence", LETTER_GAP),
    # O: ---
    ("beep", DAH), ("silence", ELEMENT_GAP),
    ("beep", DAH), ("silence", ELEMENT_GAP),
    ("beep", DAH), ("silence", LETTER_GAP),
    # S: ...
    ("beep", DIT), ("silence", ELEMENT_GAP),
    ("beep", DIT), ("silence", ELEMENT_GAP),
    ("beep", DIT), ("silence", WORD_GAP),
]
```

### QML Timer-Based Audio

Timer {
    id: sosTimer
    interval: currentInterval

    repeat: true

    property int patternIndex: 0
    property int currentInterval: 150

    onTriggered: {
        // Play/stop beep based on pattern
        advancePattern();
    }
}

function advancePattern() {
    // Cycle through SOS pattern
