# Modules App

External hardware module management.

## Features

- View connected external modules
- Configure module settings
- Monitor module status and health
- Module discovery and pairing

## Permissions

- `hardware.modules` - Access to external hardware modules

## Usage

The Modules app manages external hardware that can be connected to Waycore:

- Expansion sensors
- External antennas
- Power modules
- Peripheral devices

## Supported Modules (Future)

- Solar charging panel
- External GPS antenna
- Weather station module
- Satellite communicator
- Ham radio interface
