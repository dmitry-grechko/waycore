# Gallery App

Photo gallery and viewer.

## Features

- Photo grid view
- Full-screen photo viewer
- Swipe navigation between photos
- Photo deletion
- Photo metadata display

## Permissions

- `storage.read` - Read photos

## Usage

The Gallery app displays all captured photos:
- View photos in a grid layout
- Tap a photo to view full-screen
- Swipe left/right to navigate
- Delete photos from the viewer
