# Meshtastic App

Meshtastic mesh network chat and node management.

## Features

- Channel chat with all nodes in range
- Direct messaging (encrypted)
- Node discovery and status
- Node details and signal quality
- Favorite contacts

## Permissions

- `mesh.send` - Send mesh messages
- `mesh.receive` - Receive mesh messages
- `mesh.nodes` - View node list

## Usage

The Meshtastic app provides a complete mesh communication experience:
- View channel chat and send broadcast messages
- Open direct message conversations with specific nodes
- Browse all nodes in range with battery and signal info
- Mark favorite contacts for quick access
