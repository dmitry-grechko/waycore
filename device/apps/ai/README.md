# AI App

AI Assistant with chat, image classification, and knowledge queries.

## Features

- Chat with local AI models (Phi-3 Mini, Llama 2)
- Image classification and Visual Q&A
- Conversation history
- Multimodal queries (image + text)

## Permissions

- `ai.chat` - Send chat messages to AI
- `ai.classify` - Classify images
- `storage.read` - Read images from gallery

## Usage

The AI app provides an interactive chat interface for querying local AI models. Users can:
- Ask questions about outdoor activities, survival, navigation
- Attach images for classification or Visual Q&A
- View and continue past conversations
